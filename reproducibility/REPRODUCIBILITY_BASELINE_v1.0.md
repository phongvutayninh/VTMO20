## 2. Purpose

This document formally establishes and freezes the reproducibility evidence baseline associated with the public release of VTMO20 Core v1.0.0.

The baseline consolidates the public ontology artifact, integrity evidence, release metadata, reproducibility protocol, executed verification record, and evidence index into a stable research evidence package.

The purpose of this baseline is to provide a fixed reference point for:

1. independent inspection;
2. artifact integrity verification;
3. ontology reproducibility assessment;
4. release provenance tracking;
5. persistent-identifier verification after W3ID activation;
6. future comparison with subsequent VTMO20 releases.

## 8. Freeze Policy

The evidence components included in this baseline are frozen as the reproducibility reference package for VTMO20 Core v1.0.0.

After this declaration:

1. frozen evidence records should not be silently modified;
2. substantive corrections must be explicitly documented;
3. future ontology releases must establish a new versioned reproducibility baseline;
4. the existing SHA-256 reference must remain associated with the exact artifact verified in this baseline;
5. W3ID activation does not invalidate this baseline;
6. final W3ID verification may be added as a subsequent evidence record without rewriting the historical verification state documented here.

---

## 9. Baseline Change Control

If a substantive error is discovered in a frozen baseline component, the change must be traceable.

The correction should document:

- affected component;
- reason for correction;
- previous state;
- corrected state;
- date of correction;
- responsible maintainer;
- effect, if any, on reproducibility conclusions.

No substantive correction should be represented as though it formed part of the original frozen state.
